❓ Help / How to Use

Basic Use

  1. Choose a mosque from the dropdown at the top.
  2. Click + Add Location to create storage locations first.
  3. Click + Add Item to add items to a location.
  4. Use + / − buttons or type a number to change quantity. It saves automatically.
  5. Click Edit to change details, Notes to add notes, Delete to remove.

Print / Export

  • Print PDF — prints the current mosque's inventory. Use your browser's "Save as PDF" option.
  • Export CSV — downloads a spreadsheet file for the current mosque only.

Backup (Important!)

  • Backup — downloads a JSON file with ALL data for the current mosque. Do this weekly and save to Google Drive or email it to yourself.
  • Restore — upload a JSON backup file to restore data.
  • Warning: Data is stored in your browser only. If you clear browser cache, data is lost. Always keep backups.

Data is Separate per Mosque

Each mosque has its own data. Printing, CSV, and backup only include the currently selected mosque.

No Money, No People Names

This app deliberately does not track prices, values, or people's names. Use Notes if you need to remember something like "who took it".
